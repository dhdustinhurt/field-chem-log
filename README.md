# Field Chemical Log

Offline spray-record app for the phone. Open the link once in Safari, tap Share → **Add to
Home Screen**, and it runs from the icon with no internet connection.

- Records fields, chemicals and applications; does the rate math (gal/acre, product per
  tank, lb active ingredient per acre) as you type.
- Warns when a pass would push a field over a per-season active-ingredient cap.
- Exports an Excel workbook through the share sheet → Save to Files or Mail.
- Nothing leaves the phone. Use **Export → Save backup file** now and then; there is no cloud.

The built-in chemical library is a starting point. Check EPA numbers and a.i. strengths
against the label on the jug — the app flags anything you haven't confirmed.
